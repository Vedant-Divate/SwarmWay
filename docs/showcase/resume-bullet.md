# Resume bullet (Section 2.1 positioning — edit into your voice)

Built Swarmway, an interactive 3D workbench for optimal multi-agent path
finding: a pure-Python Conflict-Based Search (CBS) solver with an independent
validity checker and brute-force optimality cross-checks, benchmarked against
a Prioritized Planning baseline on 24 MovingAI MAPF cells (60 s budget;
headline run 20261105-1754-5db8a24-dirty-headline: 48/72 solved, CBS optimal
where it solves, medians reported over solved runs with timeouts in
denominators). Frontend is a React/TypeScript + Vite SPA deployed to GitHub
Pages (offline-first, works with no backend). Reproducible artifacts under
data/results/<run-id>/; every number cites a run ID.

Deployed: https://Vedant-Divate.github.io/SwarmWay/
Repo: github.com/Vedant-Divate/SwarmWay
